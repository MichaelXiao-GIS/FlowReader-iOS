# 菠萝阅 | Flow Reader

<img src="Design/FlowIcon-preview.png" width="96" alt="菠萝阅分层图标">

面向个人阅读的原生 iOS 菠萝包轻小说第三方客户端。SwiftUI、系统 Liquid Glass 导航、Books 风格书架与阅读排版，无广告、无第三方分析 SDK。

**要求：iOS 27.0 或更新版本。** 使用 Xcode 27.2 / iOS 27.2 SDK 构建，iPhone 18 Pro 与 iPhone Duo机型测试验证。Duo 使用原生侧边标签栏，阅读目录采用系统自适应弹层；内外屏及折叠姿态交给系统导航和安全区域适配。

## 安装

从 [Releases](https://github.com/MichaelXiao-GIS/FlowReader-iOS/releases) 下载 `FlowReader-1.7.1-unsigned.ipa`。这是 **arm64 真机未签名 IPA**，需自行用个人 Apple 开发签名或现有侧载工具重新签名安装；它不含开发者证书、描述文件或 Apple 账号。

## 功能

- 在线搜索、推荐、书籍详情、分卷目录和免费章节阅读；“现在就读”推荐改为纵向浏览，常规字号每行三本。
- 点按书籍详情中的作者名进入原生作者页，查看头像、简介、粉丝数和全部公开小说作品；自适应作品网格支持继续打开作品与原生返回。
- 一级“书库”整合云端书架与本机书籍，普通手机宽度默认三列、宽屏自动增加列数，无障碍大字号减少列数；支持搜索、分类筛选与继续阅读；单个收藏分类失败时保留已读取作品，并提示未完成的同步。
- 云端书架按最近阅读排序，封面下显示按章节计算的阅读百分比；读取官方云端最近章节，不同的云端位置可主动选择继续阅读，同一章保留本机段落位置。
- “我的”页统一使用“登录菠萝包”，同一账号用于云端书架、阅读记录、已授权正文、VIP 等级、签到、福利与有声；旧网页授权收纳在“兼容设置”，日常阅读无需再授权，旧授权失效不会阻断主账号。
- 已授权 VIP 正文优先使用官方 App 文字接口，固定关闭自动订阅；拒绝未授权或未能确认格式的正文，不把加密内容显示为小说。
- App 正文按上游字典还原字符，旧版未还原缓存自动离线修复；网页图片识别与本地导入不会重复转换。
- 目录结合当前阅读权限与官方订阅记录，区分已购买、可阅读与需订阅；读取失败保留已确认结果并提供重试。
- 账户独立显示火券、代券、金币；单章订阅先读取真实报价与余额，明确确认后提交，结果不明时只查状态、不自动重发。
- 日常福利任务列表、真实进度、手动接取任务和领取已完成任务奖励；接入真实前台小说阅读时长上报，返回福利页查看服务器确认的进度。签到沿用独立签到入口，不重复提交。
- 会员权益礼包：每日代券、每周代券、漫画阅读券、补签卡，按服务器会员资格及冷却时间显示和领取。
- 密码只用于当次登录，不持久化；网页与 App 会话隔离保存在系统钥匙串。
- 章节选择下载，暂停、恢复、取消；重启后未完成任务暂停，避免自动继续请求。
- 本地书库、TXT / GB18030 导入、阅读进度恢复、字号、行距、字体与主题设置。
- 沉浸式全屏阅读，默认隐藏阅读工具；滚动阅读轻点正文、仿真翻页轻点页面中央，即可呼出关闭、目录与设置。
- 阅读目录打开时自动定位当前章节，支持记住正序／倒序排列，以及一键回到当前章节；倒序只影响目录显示，不改变正文的上下章顺序。
- 阅读工具采用左上书签、右侧玻璃工具栏及底部章节进度条；书名与章节只在正文页眉显示一次；本机书签保存具体章节和文字位置，可从书签列表返回。
- 默认上下滚动，可在阅读设置切换仿真翻页；使用公开 Metal API 绘制随二维手势弯曲的纸面，支持拖回取消及轻点页边翻页。开启“减少动态效果”时，使用原生分页滑动替代卷曲动画。
- 仿真翻页支持可选横屏双栏：阅读区域横向、每栏正文宽度至少 240 pt 且可容纳约 8 个当前字号的字、正文高度至少 240 pt 时显示双页。Core Text 按页排版，以段落和段内 UTF-16 位置保存阅读锚点，支持尺寸与字号变化后重新定位。
- 保存当前阅读页面、章节及段内位置，进程重新启动后恢复；明确关闭阅读后不会再次自动打开。书库页签也会保留。
- 系统语音朗读、连续章节、有声音轨播放、睡眠定时、锁屏控制、单集离线下载和音频分享。
- 导出已下载正文为 TXT、Markdown 或 EPUB。

## 构建

无需第三方依赖或项目生成工具。Xcode 需安装 Apple Metal Toolchain（Settings → Components，或运行 `xcodebuild -downloadComponent MetalToolchain`）。直接打开 `FlowReader.xcodeproj`，选择 `FlowReader` scheme。个人签名时在 Signing & Capabilities 中选择自己的 Team，并按需修改 Bundle Identifier。

```sh
# 创建可重新签名的真机 IPA
./scripts/package-unsigned.sh

# 运行测试；替换为自己的模拟器名称
xcodebuild -project FlowReader.xcodeproj -scheme FlowReader \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' \
  CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- test
```

模拟器测试需要本地临时签名，才能使用系统钥匙串；上面的 `CODE_SIGN_IDENTITY=-` 不需要开发者证书。发行脚本仅对待自行签名的真机 IPA 关闭签名。

`scripts/generate-project.py` 可重建 Xcode 工程。工程使用文件系统同步目录，新增 Swift 文件会自动收录。`--demo` / `--uitesting` 启动参数使用明确标注的原创样书，正常启动请求真实服务。

## 使用边界

本项目独立于 SFACG 官方，接口可能随服务端调整。VIP 文字由官方 App 接口验证权限后读取；阅读、下载与翻页不会自动创建订单，单章购买需单独确认。仅使用网页登录的兼容路径仍通过官方授权图片与本机 Apple Vision 识别。网页与主账号不同时，不混用权限或阅读进度。有声音轨依赖账号权限。

日常福利进度以官方服务端为准。连接账号服务、手动接取阅读任务后，本应用只累计可见小说正文的真实前台时间；加载、设置、后台、锁屏及连续两分钟无阅读操作时暂停。本地导入、演示书籍与自动朗读不计入；计时不跨进程补算，上报结果不明不重复提交，网络失败时可能少记该段。分享、充值与订阅等任务须实际完成官方条件后刷新领取，不模拟完成任务。会员成就、生日礼包与广告奖励不在本版本范围。新福利与会员礼包已验证真实状态读取，未替用户执行真实领奖测试。

网页兼容路径的图片识别仍可能有错字。真实授权音频、真机重新签名后的前后台行为及实际刷新率仍需验证。关于页面提供不含账号或阅读内容的本地运行诊断，用于区分进程重启和同一进程返回。漫画与 EPUB 导入不包含在本版本。下载应保持应用在前台，iOS 可能挂起后台网络任务。

验证结果与机型截图见 [验证说明](docs/VALIDATION.md)。APK 核对证据、接口来源与未确认的部分见 [接口兼容记录](docs/API_COMPATIBILITY.md)。
